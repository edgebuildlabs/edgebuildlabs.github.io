What this is

One person, a fleet of AI agents on a single server, and one discipline that turns out to matter more than any of the tooling.

An agent will tell you it is done. The tests never ran, the file was never written, the service is not up. The claim was generated from context, not read off the machine — and a confident report looks exactly like a true one until somebody asks for the receipt.

That is not a model defect you can prompt away. It is a missing contract.

The rule

Every claim of state carries a source and a date — or the words NOT VERIFIED.

A claim of state is any sentence saying something is or was the case. The mark travels attached to it: path:line (date), command (now), URL (date) — or NOT VERIFIED, with half a line saying why. Opinion and reasoning carry nothing; they are visibly not facts.

It sounds trivial. It is not. It forces the distinction between memory and observation at the one moment where noticing it changes the outcome: while the sentence is being written.

STARTED  !=  COMPLETED  !=  VALIDATED  !=  PASS

A live process, an exit code of zero and the word “done” all sit upstream of PASS. Tests passing is not validation — it is evidence that the code does what the test says, which is a much smaller claim than the one usually made from it.

What it built

Living World is an Ultima Online shard on ModernUO, running on one VPS since 5 September 2026. It is a game server, and it is also the load test for the method.

  • rootless Podman, with a systemd Quadlet as the single recreation path
  • --read-only, --cap-drop=all, --security-opt=no-new-privileges, non-root user namespace
  • image pinned by digest, not by tag
  • daily backup with a restore that was actually performed, not assumed
  • a dated evidence trail and an append-only decision ledger behind every one of those choices

None of that configuration was written by hand. The entire human contribution was asking “did you verify that, or are you inferring it?” until only the verified part was left.

The shard has almost no players, and that is not the point of it. A running server is something a stranger can connect to and check for themselves, which is worth more than any screenshot.
